# Grocery List

A mobile-friendly grocery list for planning a shopping trip. Add items, set quantities and prices, track what is in your cart, and compare cart spending with a daily budget. The app is built with TypeScript and Vite, can be installed as a Progressive Web App (PWA), and includes an Android project powered by Capacitor.

## Features

- Add and remove grocery items.
- Set each item's quantity and unit price; see line totals and the planned total.
- Mark items as in the cart and see the cart total and shopping progress.
- Set a daily budget and see how much remains or how far spending is over budget.
- Select and delete multiple items, or start a new trip by clearing cart checkmarks.
- Save the list in browser/device local storage. No account or server is required.
- Install the web app on supported browsers, or run it as an Android app.

Prices and totals use Philippine pesos (PHP). The budget is saved for the current local calendar date and must be set again the next day. Grocery items stay in local storage until removed or browser/app data is cleared. Data is stored on the device and is not synchronized between devices.

## Requirements

- Node.js and npm (use a current Node.js LTS release).
- For Android builds: Android Studio with an Android SDK and a compatible JDK/Gradle environment.

## Run locally

From the repository root:

```sh
npm install
npm run dev
```

Vite prints a local URL. Open it in a browser. To test on a phone over the same Wi-Fi network, use the network URL printed by Vite.

## Available scripts

```sh
npm run dev       # Start the Vite development server (listens on the network)
npm run build     # Type-check with TypeScript, then create the production web build
npm run preview   # Serve the production build locally
```

The production web files are written to `dist/`. This folder is generated and should not be committed.

## Install as a PWA

Build and serve the app over HTTPS (or use `localhost` during development). In a supported browser, use its install option (for example, “Install app” or “Add to Home Screen”). The web app manifest and service worker are generated by `vite-plugin-pwa`; the app icons are in `public/`.

## Run on Android

The checked-in `android/` folder is the native Capacitor Android project. After changing web code, build the web app and copy the updated assets into the Android project:

```sh
npm run build
npx cap sync android
npx cap open android
```

Use Android Studio to select a device or emulator and run the app. To build a debug APK from the command line after syncing:

```sh
cd android
./gradlew assembleDebug
```

The debug APK is created under `android/app/build/outputs/apk/debug/`. Keep signing keys and local SDK configuration out of version control.

## Project layout

- `src/` — application code, styles, types, and local-storage helpers.
- `public/` — app icons and static assets.
- `assets/` — source artwork.
- `android/` — native Android project generated and maintained with Capacitor.
- `capacitor.config.ts` — Capacitor app ID, display name, and web build directory.
- `vite.config.ts` — Vite and PWA configuration.

## Data and privacy

The app currently has no backend. Grocery items and the daily budget are stored in the browser or app's local storage on the device. Clearing site/app storage removes saved data. Installing the app on another device starts with an empty list.
